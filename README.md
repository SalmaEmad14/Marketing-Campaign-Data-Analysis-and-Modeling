#  Marketing Campaign Data Analysis and Modeling

##  Project Overview
This project analyzes a marketing campaign dataset to uncover customer behavior patterns and build machine learning models that predict whether a customer will respond to a marketing campaign.

##  Objectives
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Visualize customer demographics and campaign performance.
- Build and evaluate machine learning classification models.
- Compare model performance using different evaluation metrics.
